# Report analysis

Explain only supplied events and evidence. Never invent screenshots, actions, reasoning summaries, or usage.
Reference observations, actions, or spans for important conclusions. Explicitly identify broken evidence links.
Distinguish workflow completion, action execution, and interaction verification. Without an authoritative inventory, state coverage over the discovered set.
Retain failures, blockers, and the information needed for recovery. Fixture records only verify framework behavior.
Write reports in English. Preserve original game/user text as attributed evidence when necessary.
