# Coverage and evidence definitions

Discovered: an observation contains a potential or confirmed interaction target.
Attempted: an actual action was recorded, but its effect is not necessarily known.
Verified: post-action evidence supports the expected result.
Blocked: account, level, schedule, permission, or environment conditions prevent continuation.
Unknown: evidence is missing, execution was interrupted, or the result is uncertain.

A coverage denominator must come from an explicit test inventory or the discovered set, with that scope stated. Run completion does not mean full game coverage.
Missing reasoning summaries and usage are unavailable values, not empty reasoning or zero usage.
